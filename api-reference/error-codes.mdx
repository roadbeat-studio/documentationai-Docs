## How to use error codes

Every error response from the Studio API carries a stable, machine-readable `code` next to the HTTP status (see [Error Responses](/api-reference/overview#error-responses) for the full body):

```json
{
  "statusCode": 409,
  "error": "Conflict",
  "code": "CONTENT_TYPE_IN_USE",
  "message": "Cannot delete content type \"event\": 12 content item(s) still reference it. Delete or reassign the content first.",
  "params": { "contentTypeId": "event", "count": 12 },
  "requestId": "req_a1b2c3"
}
```

- **Branch on `code`, not on `message`.** Codes are stable across releases; messages are English prose and may be reworded.
- **Translate by `code`.** `params` carries the values the message mentions, so a client can build its own text in the user's language. The Studio UI does exactly this for all 24 interface languages and falls back to `message` for a code it does not know yet.
- **Expect new codes.** Treat an unknown code like its HTTP status.

<Callout kind="info">
  The **Status** column shows the status a code is returned with. A few codes are raised in more than one place with different statuses; those rows list each one.
</Callout>

## Codes derived from the status

Errors that do not carry a specific code get one derived from their status, so `code` is always present:

| Code | Status | When |
|------|--------|------|
| `VALIDATION_FAILED` | 400 | Request-body validation failed; `message` is an array with one entry per violation |
| `BAD_REQUEST` | 400 | Other malformed requests |
| `UNAUTHORIZED` | 401 | Missing or invalid authentication |
| `FORBIDDEN` | 403 | Not allowed |
| `NOT_FOUND` | 404 | Route or resource not found |
| `CONFLICT` | 409 | Conflicting state |
| `PAYLOAD_TOO_LARGE` | 413 | Request body or upload too large |
| `UNSUPPORTED_MEDIA_TYPE` | 415 | Unsupported content type |
| `UNPROCESSABLE_ENTITY` | 422 | Semantically invalid request |
| `TOO_MANY_REQUESTS` | 429 | Rate limit reached — see [Rate Limiting](/api-reference/overview#rate-limiting) |
| `UPSTREAM_UNAVAILABLE` | 502, 504 | An upstream service failed or timed out |
| `SERVICE_UNAVAILABLE` | 503 | A required service is unavailable |
| `INTERNAL_ERROR` | 500 | Unexpected server error — report it with the `requestId` |

## General

| Code | Status | Meaning |
|------|--------|---------|
| `RESOURCE_NOT_FOUND` | 404 | The item does not exist **in your organization** (tenant isolation — items of other organizations are never visible) |
| `ACTION_PREVENTED` | 403 | A plugin prevented the action (e.g. publishing unapproved content under a workflow); `message` gives the reason |
| `QUERY_FILTER_UNKNOWN` | 400 | `filter[field]` is not filterable on this endpoint; `params.allowed` lists the fields that are |
| `QUERY_FILTER_NOT_BOOLEAN` | 400 | The filter value must be `true` or `false` |
| `QUERY_FILTER_NOT_NUMBER` | 400 | The filter value must be a number |
| `QUERY_FILTER_VALUE_INVALID` | 400 | The filter value is not one of `params.allowed` |
| `QUERY_SORT_INVALID` | 400 | `sortBy` is not a sortable column of this endpoint; `params.allowed` lists them |

## Pro plugin codes

Pro plugins return the same error body and define their own codes, typically prefixed with the plugin's area — for example:

| Code | Status | Meaning |
|------|--------|---------|
| `AI_PROVIDER_FAILED` | 502 | The AI provider answered with an HTTP error (`params.provider`, `params.status`). The provider's response body is logged, never returned |
| `AI_PROVIDER_UNREACHABLE` | 502 | The AI provider could not be reached |
| `AI_SOURCE_URL_BLOCKED` | 400 | An image or audio URL for the AI points at a private or internal address (`params.hostname`) |
| `AI_REQUEST_INVALID` | 400 | The AI request is incomplete or malformed |
| `BULK_OPERATION_NOT_FOUND` | 404 | The bulk operation was not found |
| `BULK_NOTHING_TO_UNDO` | 400 | The bulk operation recorded no previous state to restore |
| `BULK_ALREADY_UNDONE` | 400 | The bulk operation was already undone |
| `BULK_ZIP_TOO_LARGE` | 400 | The selected assets exceed the ZIP download limit (`params.size` / `params.limit` MB) |

See the [Studio Pro documentation](https://studio-pro-docs.roadbeat.net/introduction) for each plugin's codes.
